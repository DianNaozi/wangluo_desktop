# 幻视图库 / Local Gallery

本地优先的图片、视频与普通文件图库。导入时应用会扫描所选文件或文件夹，将原文件复制到受管资源目录，并保留来源文件不变。

## 开发

PowerShell 若禁止执行 npm 脚本，请使用：

```powershell
npm.cmd install
npm.cmd run dev
```

可用命令：

- `npm.cmd run dev`：启动桌面开发环境
- `npm.cmd run typecheck`：运行 Vue / TypeScript 类型检查
- `npm.cmd run build`：执行类型检查并构建生产文件至 `out/`

## 架构

- `src/main`：Electron 主进程。文件扫描、SHA-256 去重、受管复制、SQLite 索引、回收站和缩略图任务都只在这里运行。
- `src/main/import`：导入任务按 FIFO 队列串行执行，单任务内最多并发处理四个文件；异常关闭后会自动恢复未完成任务。
- `src/preload`：受控 IPC 桥梁，向渲染层公开媒体库、导入队列、回收站和设置 API。
- `src/renderer`：Vue 前端。路由页面、Pinia 状态和组件位于此处。

导入内容按内容哈希去重；同一内容可以归入多个图集。删除图集只会回收不再被其他活动图集引用的受管副本；图集回收或恢复发生 I/O 失败时会保持“处理中”，可从回收站继续操作。永久删除会再次检查图集关联，不会破坏仍被使用的媒体。

默认保留原始来源文件；可在设置中启用“导入后删除源文件”，成功入库后会将源文件移入 Windows 系统回收站，并保留失败、跳过或已变化的文件。资源目录只允许在完全空的图库中切换，且新目录必须为空，应用不会迁移已有数据。启动时会将未被索引的受管对象隔离到应用回收区，保留 30 天；可导出副本，但不会自动重新加入图库。

图片和视频会在导入完成后异步生成 WebP 预览。FFprobe 最多运行 15 秒，FFmpeg 最多运行 60 秒，单个异常视频只会标记当前预览失败，不会阻塞后续队列。压缩包、符号链接和重解析点目前会被跳过。

渲染进程启用了 `contextIsolation` 和 sandbox，不能直接访问 Node.js 或用户文件系统。
